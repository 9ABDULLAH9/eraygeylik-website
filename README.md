## 🧾 Overview

**eraygeylik-website** is a Next.js-powered web application designed to deliver a dynamic, optimized user experience with streamlined development and deployment processes.

Built on `create-next-app`, it integrates modern styling with **Tailwind CSS**, enforces code quality standards with **ESLint**, and simplifies project organization through **path aliasing**. Its architecture supports efficient workflows and reliable releases via **Vercel**, while the interactive image gallery adds engaging visual content to the site.

### Why `eraygeylik-website`?

This project provides a solid foundation for building high-performance, visually appealing websites. Core features include:

- 🧩 **Modular Configuration**  
  Seamless integration of Tailwind CSS, ESLint, and Next.js settings for consistent styling and code quality.

- 🚀 **Optimized Performance**  
  Built-in support for Next.js features ensures fast load times and smooth user interactions.

- 🎨 **Engaging UI Components**  
  An interactive, animated image gallery enhances visual storytelling.

- 📁 **Simplified Development**  
  Path aliasing and streamlined scripts improve developer productivity.

- ☁️ **Effortless Deployment**  
  Vercel integration enables smooth, reliable deployment workflows.

## 🚀 Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: JavaScript  
- **Package Manager**: [npm](https://www.npmjs.com/)

---

### 🔧 Installation

Follow these steps to set up the project:

1. **Clone the repository**  
   ```bash
   git clone https://github.com/9ABDULLAH9/eraygeylik-website
   ```

2. **Navigate to the project directory**  
   ```bash
   cd eraygeylik-website
   ```

3. **Install dependencies**  
   ```bash
   npm install
   ```

---

### ▶️ Usage

To run the project locally:

```bash
npm start
```
